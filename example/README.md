# ruler_scrubber_example

A single-screen demo of [`ruler_scrubber`](../): a price scrubbed at two cents a
tick, a percentage snapped to whole steps, and a temperature drawn with an
explicit `RulerScrubberStyle` rather than from the theme.

```sh
flutter run
```

The platform folders are not checked in. `flutter create .` from this directory
generates the ones your machine needs.
